# Dataset folder

Place a CSV dataset here for reference or distribution. The dashboard currently loads data through its upload control; it does not automatically fetch files from this folder.

Recommended columns: `manufacturer`, `model_name`, `model_year`, `manufacturing_country`, `market_region`, `category`, `battery_type`, `battery_capacity_kwh`, `range_km`, `price_usd`, `annual_sales_units`, `customer_rating`.
